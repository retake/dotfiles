handoff loop の結果を報告するとき、最終結論だけを提示しない。

**Why:** ユーザーはAI同士のラリーの途中経過が見えないため、結論だけ示されても「何の話をしているのか」「なぜその結論になったのか」が分からない。

**How to apply:** handoff の要約を報告する際は以下の構造で伝える:
1. **最初の論点** — 何について議論が始まったか
2. **途中の展開** — どんな選択肢・懸念・反論が出たか（主要な転換点を2-3個）
3. **最終結論** — 何に決まったか・何が残課題か

ラリーが長い場合でも「結論: Xになりました」だけで済ませず、判断の根拠が追えるレベルの経緯を含める。
