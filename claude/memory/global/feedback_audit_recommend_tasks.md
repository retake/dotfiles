/audit-handoffs の照合・サマリ出力後、必ず「推奨タスク（優先度順）」テーブルを追加する。

**Why:** ユーザーは監査結果だけでなく、次に何をすべきかの判断材料をセットで求めている。照合結果を出して終わりだと、次のアクションを自分で組み立てる手間が残る。

**How to apply:** audit-handoffs のステップ5（サマリ出力）の直後に、以下の形式で推奨タスクを出す:
- テーブル形式: # / タスク / 出所 / コスト / 根拠
- 優先度順（コスト小・判断不要のものを上位に）
- 判断待ちのものは「判断のみ」とコスト欄に明記
- archive 作業も含める
